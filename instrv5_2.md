## 4. Архитектурное решение

### 4.1 Логическая схема взаимодействия компонентов системы

Система построена по трёхуровневой архитектуре с разделением ответственности:

**Уровень представления** — веб-серверы (роль Frontend) обеспечивают доступ пользователей через протокол HTTPS, реализованы на технологии Nuxt.js.

**Уровень бизнес-логики** — серверы приложений (роль Backend) реализуют функции обработки данных, управления базой данных и взаимодействия с внешними сервисами посредством REST API, построены на фреймворке Symfony с использованием PHP-FPM.

**Уровень данных** — серверы баз данных (роль СУБД) на платформе PostgreSQL 15, обеспечивающие надёжное хранение и управление данными в структурированном виде.

**Уровень аналитики** — компоненты машинного обучения (роль ML) выполняют анализ данных и взаимодействуют с backend для получения входных данных и отправки результатов обработки.

### 4.2 Описание компонентов системы

**Backend** (серверная часть):
- Веб-сервер Nginx для приёма HTTP-запросов
- PHP-FPM для выполнения PHP-скриптов
- Symfony — фреймворк для разработки приложения
- PostgreSQL 15 — основная база данных
- RabbitMQ — система управления асинхронными очередями сообщений
- Apache FOP — генерация PDF-документов

**Frontend** (клиентская часть):
- Node.js — платформа выполнения
- Nuxt.js — фреймворк для разработки веб-интерфейса
- Взаимодействие с backend через HTTP-запросы

**Machine Learning** (компоненты анализа):
- Python 3 — основной язык разработки
- Модели машинного обучения (TensorFlow, ONNX Runtime)
- OCR-системы (Tesseract, EasyOCR)
- Обработка текста (Pymorphy3, PyEnchant)
- Обработка изображений (Pillow, PDF2Image)
- PM2 — управление процессами Python-приложения

### 4.3 Схема подключения и сетевое взаимодействие

Все компоненты системы взаимосвязаны и работают вместе для обеспечения комплексного решения:

1. **Frontend → Backend**: HTTP/HTTPS-запросы для получения данных и отправки команд
2. **Backend → PostgreSQL**: Взаимодействие с базой данных для хранения и извлечения информации
3. **Backend → RabbitMQ**: Асинхронная отправка задач в очереди сообщений
4. **Backend → ML**: REST API для запуска моделей анализа и получения результатов
5. **ML → Backend**: Обратная передача результатов обработки
