**Введение**

Настоящий документ является основанием для выполнения работ по созданию
виртуальной инфраструктуры в рамках проекта «Внедрение
автоматизированной системы управления проектами» (далее -- ИСУП). В
документе определены цели, зоны ответственности, архитектурное решение,
спецификации вычислительных ресурсов, требования к интеграции с
системами управления и безопасности, а также правила доступа и порядок
взаимодействия компонентов.

1.  []{#_heading=h.5t94hgqy9qk4 .anchor}Цель изменения

Обеспечить вычислительными ресурсами продуктивный ландшафт для системы
ИСУП в рамках проекта «Внедрение автоматизированной системы управления
проектами».

Владелец создаваемых виртуальных машин: АО «ОСК».

2.  Описание архитектуры Системы.

Система построена по трехуровневой схеме:

Уровень представления -- веб-серверы (роль App) обеспечивают доступ
пользователей через протокол HTTPS.

Уровень бизнес-логики -- серверы приложений (роль App) реализуют функции
обработки данных.

Уровень данных -- серверы баз данных (роль СУБД) на платформе PostgreSQL
15.

Компоненты информационной системы размещаются в кластере Kubernetes. Все
виртуальные машины размещаются в кластерах виртуализации IaaS:\
Перечень создаваемых ВМ (в рамках объемов пилотного проекта):

MSK11-MSF-BD1 - База данных

MSK11-MSF-FS1 - Файловый сервер

MSK11-MSF-MC1 - Мастер сервер

MSK11-MSF-APP1-4 - Рабочие ноды (4 штуки)

MSK11-MSF-MON1 - Мониторинг и сбор диагностики

MSK11-MSF-REP1 - Репозиторий
