Введение

Настоящий документ является основанием для выполнения работ по созданию
виртуальной инфраструктуры в рамках проекта «Трансформация системы
коммерческого учета ДРП и переход на сквозной учет по ФИФО». В документе
определены цели, зоны ответственности, архитектурное решение,
спецификации вычислительных ресурсов, требования к интеграции с
системами управления и безопасности, а также правила доступа и порядок
взаимодействия компонентов.

2.  Описание архитектуры Системы.

Примечание -- Заполняется руководителем проекта совместно с подрядной

Система построена по трехуровневой схеме:

Уровень представления -- веб-серверы (роль App) обеспечивают доступ
пользователей через протокол HTTPS.

Уровень бизнес-логики -- серверы приложений (роль App) реализуют функции
обработки данных, интеграцию с внешними системами (Диадок, СПИМЕКС) и
взаимодействие с подсистемой сбора показателей.

Уровень данных -- серверы баз данных (роль СУБД) на платформе Microsoft
SQL Server 2016 Enterprise в составе отказоустойчивого кластера.

Все виртуальные машины размещаются в кластерах виртуализации:

серверы приложений -- в кластере SPB99-ESXCL03;

серверы СУБД -- в кластере SPB99-ESXCLMSSQLENT.

виртуализации к коммутаторам выполнено по схеме L1, L2, L3. Схема

настроена виртуальная инфраструктура, обеспечивающая функционирование
продуктивного ландшафта системы ЕАСКУ в соответствии с проектной
архитектурой. Все изменения соответствуют требованиям технической и
